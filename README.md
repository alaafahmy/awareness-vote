# محاكاة مسابقة مدار

تجربة توعوية آمنة لمشاركين مصرح لهم مسبقًا. تبدأ كمسابقة تقنية، ثم يعرض المشرف النتيجة التوعوية. لا يجمع التطبيق بريدًا أو كلمات مرور أو رموز تحقق أو عناوين IP.

يتطلب التشغيل Node.js 20.19 أو أحدث.

عند التشغيل المحلي يقرأ الخادم ملف `.env.runtime` تلقائيًا إن وُجد. الملف مستبعد من Git ومخصص للأسرار المحلية فقط.

## التشغيل المحلي

1. جهّز قاعدة MongoDB Atlas وخذ رابط الاتصال.
2. عرّف المتغيرات في PowerShell ثم شغّل التطبيق:

```powershell
$env:MONGODB_URI='mongodb+srv://...'
$env:ADMIN_KEY='استخدم-مفتاحًا-طويلًا-وعشوائيًا'
$env:CODE_HASH_SECRET='استخدم-سرًا-آخر-طويلًا-وعشوائيًا'
$env:PARTICIPANT_CODES='MDAR-7K2P,MDAR-9X4Q,MDAR-3N8T'
npm install
npm start
```

3. افتح `http://localhost:3000`، ولوحة الإدارة على `http://localhost:3000/admin.html`.

في الإنتاج أضف القيم نفسها من إعدادات Render أو Vercel. ملف `.env.example` مرجع لأسماء المتغيرات فقط، والتطبيق لا يقرأ ملفات البيئة تلقائيًا.

## متغيرات البيئة

- `MONGODB_URI`: رابط MongoDB Atlas. مطلوب؛ لا يوجد تخزين مؤقت بديل.
- `DB_NAME`: اسم قاعدة البيانات، والقيمة الافتراضية `awareness_competition`.
- `ADMIN_KEY`: مفتاح طويل وعشوائي لحماية واجهات الإدارة.
- `CODE_HASH_SECRET`: سر مستقل لإنشاء بصمة غير قابلة للاسترجاع لرمز المشاركة.
- `PARTICIPANT_CODES`: قائمة رموز المشاركين المصرح لهم، مفصولة بفواصل.
- `PORT`: منفذ التشغيل المحلي.

## البيانات المحفوظة

- الاسم الأول أو الاسم المستعار.
- مرجع مختصر وبصمة مشفّرة لرمز المشاركة، دون حفظ الرمز الأصلي.
- نسخة الشروط والحالة والتوقيت.

لا يُحفظ بريد، كلمة مرور، رمز مشاركة أصلي، عنوان IP، أو معلومات متصفح.
